This design is a rudimentary model of a skateboard that has proportional measurements with actual skateboards.
The model contains several parts, such as the skateboard body, wheel, bearing, and axle, which are then assembled into the actual skateboard.
This project was created for my engineering class in early 2025 and the work was completed at the end of the school year (early June).
