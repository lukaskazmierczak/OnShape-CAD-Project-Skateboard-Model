__**Skateboard CAD Model | Onshape**__

**Project Overview**

A 3D skateboard model designed and assembled using Onshape, a cloud-based computer-aided design (CAD) platform. Created as part of a high school intro to engineering course during spring 2025, this project explores component modeling, proportional design, and mechanical assembly. The model uses dimensions proportional to a real skateboard and includes several individually modeled components assembled into a complete design.

**Model Components:**

-Skateboard deck: Main body of the skateboard <br>
-Wheels: Modeled as individual components <br>
-Bearings: Included in the wheel assemblies <br>
-Axles: Components connecting the wheels to the skateboard <br>

**CAD Skills Demonstrated:**

-3D modeling using Onshape  <br>
-Designing individual mechanical components  <br>
-Applying proportional measurements  <br>
-Combining components into a complete assembly  <br>
-Visualizing a mechanical design in three dimensions <br>
